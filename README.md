# 🏆 Featured Work:
- **[Conflict-Aware RAG Routing](https://github.com/RAG-Routing-Via-Context-Confliction/RAG_Router_Via_Context_Conflict)** · first author, IEEE IS'26 ([paper](https://github.com/RAG-Routing-Via-Context-Confliction/RAG_Router_Via_Context_Conflict/blob/main/paper/conflict_aware_rag_routing_ieee_is26.pdf))<br>
  Routes each query between a local SLM and an LLM API using NLI context conflict: ~35% fewer API calls while keeping 83–92% of Always-LLM F1 on 3,000 multi-hop questions.
- **[VietSign Edge AI](https://github.com/VietSign-Edge-AI/VietSign-Edge-AI)** · team lead<br>
  Offline Android traffic-sign recognition (YOLOv8n + MobileNetV3, distillation, pruning, INT8 QAT): 5.07 MB for both models, 82.3% mAP@0.5, 91.9% Top-1 on 48 classes.
- **[Luc Bat Poem Generator](https://github.com/zafkielzz/Luc_Bat_Poem_Generator)** · solo<br>
  Constrained decoding on Qwen3-8B for Vietnamese lục bát poetry: rule-valid poems from 0/12 to 12/12 on held-out prompts.
- **Multi-Task Stock Transformer** · capstone, vice team lead (ongoing)<br>
  Multimodal data and models for Vietnamese stocks: prices, financial statements, news, ESG and macro data.

📚 Also: *Probabilistic Modeling of Stock Breakout Success during Consolidation Phases in the Vietnamese Equity Market*, ICITDA 2026 (co-author, accepted) · [PDF](https://zafkiel-portfolio.vercel.app/icitda_2026_stock_breakout.pdf)
